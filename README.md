# Kirtan Tutorials posts

Finished media for the Instagram, TikTok and Pinterest posts of Kirtan Tutorials (kirtantutorials.com).

- `media/YYYY-MM-DD/` holds one folder per day. Posts are PNG files at 1080x1350, reels are MP4 files at 1080x1920 with a `-cover.png` image.
- `posts.csv` and `posts.json` list every post in order: date, time, format, series, topic, files, reel cover and the full caption with its 5 hashtags.
- Month 1 runs from 26 October to 24 November 2026, 5 posts per day.

The repository must stay public so that Metricool can fetch the files by URL:
`https://raw.githubusercontent.com/<user>/<repo>/main/<path>`
